Cara Edit Soal

Soal di game ini diambil dari Google Sheets. Ubah isi sheet, soal di game akan ikut berubah (perlu beberapa menit sampai muncul, dan tekan "Muat Ulang Soal" di bawah).

1. Sheet Kata (Membaca)

Kolom: kata, emoji, tampil, jawaban, salah1, salah2
tampil = kata dengan bagian kosong (pakai __) — boleh ditaruh di depan, tengah, atau belakang
jawaban = suku kata yang hilang
Contoh baris yang benar:

baju, 👕, ba__, ju, mi, ka
api, 🍎, a__, pi, ta, ku
keong, 🐌, ke__, ong, tan, mas
paus, 🐳, __us, pa, sa, ba

⚠️ Penting: pastikan blank memang memisahkan suku kata yang benar (contoh: "a-pi" bukan "ap-i"), supaya anak tidak belajar pemisahan suku kata yang keliru.

⚠️ Pilih kata 2 suku kata saja (pola KV-KV seperti "i-kan", "ma-can"). Kata 3+ suku kata seperti "ke-lin-ci" umumnya masih terlalu sulit untuk anak kelas 1 yang baru belajar membaca.

2. Sheet Angka (Berhitung)

Kolom: emoji, jumlahBenar, salah1, salah2
Contoh baris: 🍎, 4, 3, 6

3. Setelah selesai edit

Di Google Sheets: File → Bagikan → Publikasikan ke web → pilih sheet-nya → format CSV → salin link. Tempel link itu ke variabel SHEET_URL_MEMBACA / SHEET_URL_BERHITUNG di kode (dekat atas file JS).
